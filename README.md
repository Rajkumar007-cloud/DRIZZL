# 🌧️ DRIZZL

Regime-Aware AI Post-Processing of Monsoon Rainfall Forecasts

## Overview

DRIZZL is an AI-powered rainfall post-processing system that improves Numerical Weather Prediction (NWP) rainfall forecasts by identifying the prevailing monsoon regime and applying regime-specific corrections.

## Features

- Weather Regime Classification
- Active / Break / Depression Models
- Bias-Corrected Rainfall Forecasts
- Heavy Rainfall Probability
- Forecast Reliability Score
- IMD Rainfall Categories
- Risk Intelligence Engine
- Interactive Plotly Visualizations

## Tech Stack

Python | Streamlit | Scikit-learn | XGBoost | Plotly | Pandas

## Workflow

Weather Inputs
→ Regime Classifier
→ Regime-Specific Correction Model
→ Corrected Rainfall Forecast
→ Risk Assessment
→ Visualization Dashboard
